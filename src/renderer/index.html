BEFORE CAMERA ACCESS

Camera & data consent

Let the participant review this themselves. Do not agree on their behalf. The camera stays off unless they agree, and they can stop it or withdraw at any time.

◉

Camera access

Agreeing starts SmartSpectra and requests a live, muted camera stream. No microphone is requested. SmartSpectra processes the live frames on this computer; this app does not record video or send it to the Python session backend. You can stop the measurement or withdraw consent at any time. Electron and the operating system may show a camera permission prompt.

⌁

What is measured

This app requests only SmartSpectra breathing-rate metrics and displays the live estimate, confidence, and stability when available. Early readings may be unavailable until a full measurement window completes. Pulse, HRV, and facial-expression or sentiment analysis are not requested. These wellness signals are not evidence of honesty and must not be used for diagnosis, treatment, or medical decisions.

▤

Storage, sharing & deletion

After you agree, this app saves one session's question prompts and notes in ~/.signal-session/sessions.sqlite3 on this computer under the account running the server. It expires 30 days after first save; edits do not extend that period. Expired data is physically removed the next time the local server starts or the session API is used, so its file can remain on disk longer if the server is not run. Use “Delete saved copy” to remove it sooner; withdrawing consent stops SmartSpectra and attempts to delete it. Camera frames and live breathing metrics are not written to the session database; uploaded prompt media is previewed locally and is not saved by this app. The local backend binds to this computer only and does not share session notes or prompts. The SDK uses your API key to authenticate with Presage; no optional AI service is used. Its terminal shows request paths/status, not note or prompt contents.

◇

SDK telemetry & AI

SmartSpectra SDK telemetry is explicitly disabled in this app. The SDK makes a Presage authentication request when a measurement starts; the API key is stored only in your local .env file and is not saved with session notes. No optional AI service is used.

Only the participant may agree. Do not monitor anyone without their knowledge and consent. You can choose “Not now” without starting SmartSpectra. The saved copy expires after 30 days; physical removal happens on the next server run or API use. You can delete it sooner.
